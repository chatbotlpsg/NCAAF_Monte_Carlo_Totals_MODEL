Validated corrections
---------------------
1. ESPN display team names are separated from ESPN school/location model keys.
2. Canonical state resolution is deterministic and protects against unsafe prefix
   matches (e.g. Arkansas-Pine Bluff must NOT resolve to Arkansas).
3. Sparse/unresolved teams receive a dynamic, high-uncertainty prior rather than
   disappearing from the model slate.
4. Missing Odds API event mapping no longer blocks the pure football model.
5. Missing stadium weather / starter-QB mapping lowers confidence but does not erase
   model-only projections.
6. Full-game model board contains one row per successfully simulated game.
7. Team-total model board contains two rows per successfully simulated game.
8. First-half model board contains one row per successfully simulated game.
9. Master EV board is a separate exact-price layer and always has a readable schema,
   even when zero sportsbook candidates exist.
10. EV rows are explicitly tagged UNCALIBRATED / PROVISIONAL_UNCALIBRATED.
11. Python stake recommendations are disabled while calibration status is UNCALIBRATED.
12. Python-side close capture and postgame audit commands/packages were removed.
