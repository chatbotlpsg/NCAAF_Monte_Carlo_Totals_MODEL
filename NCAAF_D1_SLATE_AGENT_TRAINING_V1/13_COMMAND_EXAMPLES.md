# Command Examples

Preferred:
```text
9/6 NCAAF D1
```

Also valid:
```text
09/06 NCAAF D1
2026-09-06 NCAAF D1
```

Optional explicit maintenance commands:
```text
/run-ncaaf-d1-slate 2026-09-06
/capture-ncaaf-d1-results 2026-09-06
/recover-ncaaf-d1-closes 2026-09-06
/qa-ncaaf-d1-capture 2026-09-06
/handoff-ncaaf-d1-postgame 2026-09-06
```

The user should not need these for a normal slate.
