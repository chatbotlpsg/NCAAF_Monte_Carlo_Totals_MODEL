# NCAAF No-Fabrication / Data-Gap Policy

Never fabricate:

```text
odds
book names
timestamps
weather
QB status
roster status
injury status
CFBD metrics
ESPN event IDs
Monte Carlo probabilities
market-implied probabilities
fair prices
EV%
closing lines
final results
```

Use `DATA GAP` for missing information. If the gap affects trade validity, mark the row `PASS` or `WATCH` with a clear hard flag.
