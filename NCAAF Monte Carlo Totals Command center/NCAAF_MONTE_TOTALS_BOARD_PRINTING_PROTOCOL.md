# NCAAF Monte Totals Board Printing Protocol

Required output order:

1. Handoff check
2. Source / data-quality gate
3. Full-game totals board
4. Team totals board
5. First-half totals board
6. Master EV+ board
7. Monte Carlo distribution / game projections
8. Edge drivers / model risks
9. Risk room / correlation
10. Odds API usage / price freshness
11. Postgame / close-proxy audit only if attached
12. One-sentence bottom line

Never print a generic report when the user asks for boards. The boards are the product.
